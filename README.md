# SLICK

Animated static barber website for SLICK, 126 Stapleton Road, Bristol BS5 0PS.

## Run locally

Run `python3 -m http.server 4173 --directory .`, then open http://localhost:4173.

## Deploy to Vercel

Import this GitHub repository. The root `vercel.json` selects the repository root; no dependencies or build step are required.
